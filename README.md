# TryAura Homepage

A Vite-powered landing page for TryAura, an unlimited virtual try-on plugin for WooCommerce.

## Structure

- `index.html`: Entry point.
- `src/main.js`: Main JavaScript file for interactive elements (tabs, FAQ).
- `src/style.css`: Styles for the landing page.
- `public/`: Static assets.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
